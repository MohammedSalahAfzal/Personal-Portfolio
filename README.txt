# Mohammed Salah Afzal — Portfolio Website

A responsive personal portfolio website built from the information in Mohammed Salah Afzal's CV and the supplied profile photo.

## Files
- `index.html` — portfolio page
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `assets/profile.jpg` — supplied profile photo

## Run locally
Simply open `index.html` in a browser.

## Publish
Upload the folder to GitHub Pages, Netlify, Vercel, or another static hosting service.
